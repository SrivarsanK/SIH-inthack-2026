# TransitSense Requirements

## Phase 4 Requirements: CH-4 Dashboard UI & Kiosk

- [x] **REQ-CH4-01**: Dual-mode UI supporting Command Center Mode and Outdoor Stop Kiosk Mode.
- [x] **REQ-CH4-02**: Live vector tile map with CartoDB Dark Matter / MapLibre GL rendering and glowing polyline path.
- [x] **REQ-CH4-03**: Photon search-as-you-type autocomplete input snapping camera view to target stops and landmarks.
- [x] **REQ-CH4-04**: Dynamic Indian transit agency network selector (Namma BMTC, MTC Chennai One, BEST Mumbai Chalo, DTC Delhi).
- [x] **REQ-CH4-05**: Interactive Judge Inject Panel calling REST `:8001` with cause-and-effect event log.
- [x] **REQ-CH4-06**: Live API Architecture & Endpoint Inspector Modal detailing data contracts across all 5 channels.
- [x] **REQ-CH4-07**: Multimodal trip timeline with dynamic fare calculation, route stop sequence, and progress bar.
